How an idea review runs

One command, /idea-review your idea. Seven stages, in order.

  1. Playback. Restates the idea and its assumptions; asks about anything material that is unknown.
  2. Preflight. Constraint scan across 10 categories, base rates, assumption map, dated kill criteria.
  3. 23 lenses in parallel. Each reports pros, cons, hard constraints and a verdict. None are skipped.
  4. Scenarios. Best, base and worst case with numbers, six or more stress scenarios, and a pre-mortem.
  5. Cross-examination. Disagreements between lenses are resolved by the role that owns the decision.
  6. Synthesis. Pros and cons weighted equally, hard constraints, riskiest assumptions, and a recommendation: Go, Go with conditions, Park or Kill.
  7. Confirmation gate. Nothing is built, bought or sent until you answer.

How current are the standards?

Every lens has a dated "Current standards" section. They were checked against live sources on 2026-11-09, then corrected.

  • Source and date on every claim. Each fact carries a link and an as-of date.
  • Evidence is labelled. Primary, secondary or unverified. A proposal is never written up as adopted law, and a forecast is never written up as an observed rate.
  • Unconfirmed claims stay visible. Where a source could not be fetched, the claim is tagged (unverified) rather than dropped or trusted.
  • Refresh about every six months with /research, or sooner when a source contradicts a lens.

Works beyond Claude Code?

The skills are plain Markdown (skills/<name>/SKILL.md), so the content is portable. Only the install route is Claude Code specific, and only Claude Code is tested.

  • Claude Code: the /plugin install below, or copy to ~/.claude/skills/.
  • Agents with a SKILL.md skills folder (such as Codex): copy the folders from skills/ into that folder; check your tool's docs for the path.
  • Any other agent: paste a skill into the prompt, or point to it from AGENTS.md.
  • Expect differences: the parallel panel in /idea-review assumes the agent can run sub-agents; elsewhere, run the lenses one at a time. Namespaced /idea-review:<skill> commands exist only in Claude Code.

Install

Claude Code: two commands, no clone needed. Project-context files such as CLAUDE.md and projects/ are optional.

/plugin marketplace add DeepRohit-2163/idea-review-skills
/plugin install idea-review@idea-review-skills

/idea-review:idea-review a marketplace for used climbing gear

Plugin skills are namespaced: /idea-review:ceo, /idea-review:preflight and so on. Want bare /idea-review and /ceo? Copy the folders instead:

git clone https://github.com/DeepRohit-2163/idea-review-skills.git
cp -r idea-review-skills/skills/* ~/.claude/skills/
